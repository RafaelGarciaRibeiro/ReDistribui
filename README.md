# VagaCerta

Sistema de agendamento e combate ao absenteísmo em unidades básicas de saúde.

## Sobre o projeto

O VagaCerta tem como objetivo reduzir o desperdício de horários causados por faltas em consultas e exames.

O sistema permite realizar agendamentos, confirmar atendimentos, liberar horários não confirmados e registrar faltas dos pacientes.

## Objetivo

Melhorar o aproveitamento das agendas das unidades básicas de saúde e reduzir o absenteísmo.

O projeto está relacionado ao **ODS 3 — Saúde e Bem-Estar**.

## Tecnologias

- Java 17
- MySQL 8
- JDBC
- Java Swing
